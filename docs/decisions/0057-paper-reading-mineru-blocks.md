# 0057 文献主区域与 MinerU 原始块导航

- DATE: 2026-10-07
- TAGS: frontend, library, ingest
- STATUS: 块点击交互已被 0066 取代，其余仍当前
- SUPERSEDES: 0033 的文献详情面板入口；0053 的区域高亮范围限制

## DECISION

文献库与引用入口打开主区域文献页，左侧保留页面导航。会话中的项目文献列表在可调宽的右栏打开同一阅读器，返回时恢复文献列表。主区域显示授权 PDF，右侧可收起侧栏按 MinerU 原始 block type 切换列表；点击块跳到对应页，并在有可靠坐标时标出区域。解析时在版本化产物清单中登记原始块索引；业务接口按文献归属读取、筛选、分页和单块查询。引用链接使用已登记的 block ID，缺少可用坐标时仅跳页。

## REJECTED

- 以 embedding chunk 类型作为侧栏 tab：用户要核对的是 MinerU 原始结构。
- 仅在右侧抽屉查看整篇文献：主区域更适合持续阅读与定位。
- 对缺失或越界坐标猜测页面区域：错误区域会误导原文核对。

## RATIONALE

MinerU 块 ID、页码和坐标与解析产物同版本保存，导航不会依赖检索切块粒度。

## OUT OF SCOPE

PDF 文本选择、跨页区域、图表交互与旧产物批量迁移。

## OPEN

实际 MinerU PDF 的坐标框仍需浏览器回测。
