# 0023 上传与个人文献库：先返回条目，再后台处理

- DATE: 2026-10-05
- TAGS: product, ingest
- STATUS: 当前
- SUPERSEDES: `docs/overview/minimal-mvp.md` F02（已删除）

## DECISION

页面选取本地 PDF，后端校验格式、大小与基础可读性并计算 SHA-256；校验通过立即返回稳定的用户条目 ID 与 Ingestion Job 信息，页面先显示条目，解析在后台进行。重复上传复用已有 PDF 关联，不制造副本；跨用户复用解析产物，但不暴露其他用户是否存在。列表显示标题或文件名占位、加入时间、阶段与状态；无 PDF 的条目显示「待补全文」。**个人库不提供移除文献的入口。**

## REJECTED

- 上传请求内同步等待解析完成：大文件会长时间阻塞。
- 为不存在的移除能力放置界面入口：违反 0032 的文案规范。
- 让后到用户得知文件是否由他人先上传。
- 按用户复制解析产物：与 0018 的全局去重冲突。

## RATIONALE

入库成功、取得 PDF、解析完成是三件事（0021），界面必须能把它们分别显示出来。

## OUT OF SCOPE

从个人库移除文献、批量操作、文件夹与标签。

## OPEN

单文件大小上限与并发上传策略。
