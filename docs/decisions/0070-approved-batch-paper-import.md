# 0070 用户确认入库、PDF 获取与统一队列

- DATE: 2026-10-08（2026-10-09 合并整理）
- TAGS: agent, security, ingest, frontend
- STATUS: 当前
- SUPERSEDES: 0074、0077；0076 的队列详情行为

## DECISION

Agent 检索候选由用户最多选 10 篇并确认，生成绑定用户、会话、来源 URL 与 DOI、有效 15 分钟的单次批量授权；无 DOI 候选不可选。`import_selected_papers` 不接收模型提供的文献、项目或范围参数，只消费最新授权；业务服务复核会话绑定并用既有 DOI 导入逐项建任务。项目会话默认关联对应项目，全局会话不关联项目。默认通过 AgentScope HITL 逐次确认实际调用：用户点击会话页「查看并确认」打开弹窗查看本次授权文献清单，点击「确认入库」才执行；关闭弹窗保持待授权，明确拒绝才取消。账号后端可单独配置该工具「以后总是允许」以跳过此轮内容审查，但有效的单次选文授权始终不可跳过；设置页入口后置。工具结果逐项返回实际受理状态供模型继续回答。除本工具与 0049 的定时任务创建外，Agent 写工具仍不开放。

DOI 导入先尝试元数据提供的 PDF 地址；缺失或失败时按精确 DOI 查询 OpenAlex 与 Semantic Scholar 的开放 PDF 地址，逐个经 PDF 校验、对象存储和摄取流程下载，首个成功即结束。手动与 Agent 确认入库共用流程；全部失败时保留书目信息与 `pdf_unavailable`。检索结果里的 PDF 地址只供展示，不作为可信导入参数。`10.48550/arXiv.<id>` 及其规范链接归一化为 arXiv ID，优先走 arXiv 元数据与 PDF；arXiv 限流时允许有界重试和精确 DOI 的 OpenAlex 元数据回退。

全局侧栏底部的入库队列仅显示当前用户的标识符导入与 PDF 上传处理任务，合并导入和解析阶段，按阶段着色，活动任务转圈。Agent 工具成功返回后才弹提示并打开队列，开始或失败时不打开；手动批量至少一项受理才打开。点击已有文献条目的队列任务，关闭队列并在当前路由打开入库详情右侧抽屉；尚无条目时只显示进度。

## REJECTED

- Agent 自行传 DOI/URL/项目范围，或由前端传任意 PDF 下载 URL：无法证明用户选择及服务端文献身份。
- 在在线检索阶段下载 PDF、另建导入流水线，或找不到 PDF 时删除元数据条目：下载应始于明确入库，既有任务状态已覆盖过程。
- 从队列直接跳到阅读页、在工具调用开始时打开队列：应先展示处理状态，且只在成功受理后提示。
- 将外部候选视为库内 Citation：尚无已登记原文与页码。
- 仅凭模型提交的文献清单或「以后总是允许」配置直接入库：仍须消费当前会话的有效选文授权。

## OUT OF SCOPE

付费或需登录的全文、任意网页 PDF、无 DOI 候选自动入库、授权跨会话复用、历史失败任务自动重跑。

## OPEN

无。
