# 0070 用户确认的批量文献入库与统一队列

- DATE: 2026-10-08
- TAGS: agent, security, ingest, frontend
- STATUS: 当前
- SUPERSEDES: 0069 中“自动下载或导入不在范围内”；Agent 写工具禁令仅对本工具开例外

## DECISION

OpenAlex 候选项可由用户在检索结果中多选（最多 10 篇），确认后为当前用户与会话生成 15 分钟有效的批量授权。候选令牌绑定用户、会话、OpenAlex ID 与 DOI 标识符；Agent 的 `import_selected_papers` 不接收模型提供的文献、项目或范围参数，只消费最新授权一次。业务服务复核会话绑定，以现有 DOI 导入流程建立任务，逐项返回结果；无 DOI 的候选项不可选。

全局侧栏底部的入库队列展示当前用户的标识符导入与 PDF 上传处理任务，合并同一条目的导入和解析阶段；Agent 触发入库工具时弹出提示并打开队列。队列按处理阶段显示颜色，活动任务显示旋转图标。队列数据只按当前登录用户查询。

## REJECTED

- Agent 自行传入 DOI、URL 或项目范围发起下载：无法证明用户选择了具体文献。
- 将 OpenAlex 候选项直接当成库内证据：尚无可回查原文与页码。
- 另建一套导入流水线：现有 DOI 导入和摄取阶段已经承担任务生命周期。

## RATIONALE

用户选定的候选集是唯一的授权来源；工具参数保持为空，使模型不能扩大范围。统一队列让手动与 Agent 入库共用可见的处理状态。

## OUT OF SCOPE

任意网页或付费墙 PDF 下载、无 DOI 的 OpenAlex 候选自动导入、批次跨会话复用。

## OPEN

无。
