# 0021 文献条目可以没有 PDF

- DATE: 2026-10-05
- TAGS: product, data
- STATUS: 当前
- SUPERSEDES: `docs/archive/prototype.md` §2 / §4 中「有 PDF 才能存在文献」的前提

## DECISION

用户可见文献条目有独立稳定 ID，只查到元数据即可创建、列出并加入项目；补传 PDF 后 ID 与项目关系不变。对外文献资源 ID 用稳定用户条目 ID，内部共享 Paper ID 不作越权依据。PDF 与解析产物仍按 SHA-256 共享去重；同 DOI 的不同 PDF 版本不得混用 Chunk 与页码。缺全文的条目可加入项目、查看书目，但不参与全文证据检索。

## REJECTED

- 「没有 PDF 就不能创建条目」（旧原型前提）：标识符导入场景下必然出现，会让下载失败等同入库失败。
- 填假 `file_hash` 绕过模型约束。
- 靠模糊标题自动合并条目：未知版本不合并。
- 两个明确不同版本因 DOI 相同被强行合并。

## RATIONALE

入库成功 ≠ 取得 PDF ≠ 解析完成，这三个事件必须能独立发生。把它们绑成一个，界面就只能显示"失败"，把已有元数据一起藏掉。

## OUT OF SCOPE

从个人库移除条目、版本对比界面、条目合并工具。

## OPEN

无 PDF 时按标识符去重的冲突判定；补传的 PDF 与已有条目识别出冲突 DOI 时的提示形态。
