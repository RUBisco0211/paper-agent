# 0039 Credential 使用按用户派生的对称加密密钥

- DATE: 2026-10-06
- TAGS: security, agent
- STATUS: 当前
- SUPERSEDES: —

## DECISION

agent_service 持有一个随机主密钥，以用户 ID 派生各自的对称密钥；Credential API Key 用派生密钥加密，并把用户和凭据标识绑定进密文认证。主密钥只保存在服务端独立配置中，不入数据库、不交给浏览器。本地启动首次生成并保留，生产由受限密钥文件或环境配置提供；已有密文但密钥丢失时明确失败，不自动重建。

## REJECTED

- 所有用户直接共用同一数据加密密钥：缺少按用户的密钥隔离。
- 每用户随机密钥再单独持久化：增加另一套密钥库与备份协调。
- 使用非对称加密：模型调用仍需服务端解密，无法免除私钥保护，增加复杂度。

## RATIONALE

一个主密钥便于单机部署与备份，按用户派生避免复用同一数据加密密钥；主密钥泄露仍影响全部用户，必须限制访问并备份。

## OUT OF SCOPE

主密钥轮换、外部 KMS、多实例共享密钥。

## OPEN

无。
