# 0029 引用与原文核对

- DATE: 2026-10-05
- TAGS: product, data
- STATUS: 当前
- SUPERSEDES: `docs/overview/minimal-mvp.md` F07（已删除）

## DECISION

点击引用显示文献标题、已有页码范围与原文片段，并打开页面内的相关 PDF。引用按用户与会话校验，不接受模型任意生成的路径或 Citation ID。有可靠页码就跳到对应页；没有可靠定位时显示来源文献与片段，**不编造精确位置**。历史引用必须能从已保存的工具结果与回答附带证据恢复。基础翻页与缩放要有。

## REJECTED

- 区域高亮、缩放 / 旋转坐标换算、章节模糊解析、图表浏览与问答：均后置。
- 为精确定位新建独立 layout-index：0020 已明确不需要。
- 接受模型自造的 Citation ID 或任意路径：会直接绕过授权校验。
- 用通用知识填补证据不足：必须明说文献中没有足够内容。

## RATIONALE

「点引用能回到原文」是产品成立的前提，也是 0006 坚持自研 Knowledge Base 的原因。

## OUT OF SCOPE

区域高亮、图表问答、引文图谱、跨文献引用网络。

## OPEN

无可靠页码时的降级展示形态（显示片段 vs 只显示来源）。
