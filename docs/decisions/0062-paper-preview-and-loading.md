# 0062 文献预览与加载

- DATE: 2026-10-07
- TAGS: frontend, library
- STATUS: 当前
- SUPERSEDES: 0059 中侧栏预览范围的补充

## DECISION

文献信息抽屉只展示条目与处理信息，不再挂载第二个 PDF 查看器。阅读页的 PDF 加载与条目详情请求并行启动。MinerU 的图片与图表块只要有已登记图片，均在分块侧栏显示预览；点击预览打开站内大图查看器，提供放大、缩小、重置与滚动查看。

## REJECTED

- 抽屉和阅读主区域各加载一份 PDF：重复下载与渲染，抽屉空间也不足以阅读。
- 图表只显示文字描述：有解析图片时无法核对图形本身。
- 用浏览器全屏 API 查看图片：会把整个页面切换为全屏，而非站内查看器。
- 用 `localStorage` 缓存 PDF：二进制编码会膨胀，容量有限，也缺少可靠的文件版本与账号隔离。

## RATIONALE

移除重复工作并消除详情到 PDF 的串行等待，可改善文献打开时间；图表应与图片采用同一核对方式。

## OUT OF SCOPE

PDF 字节范围请求、版本化浏览器缓存、服务端缩略图、图片标注。

## OPEN

大 PDF 的首开仍要下载完整文件；若浏览器回测仍慢，再设计 Range 接口与 PDF.js 分段读取。缓存需先确定文件版本标识、容量和退出登录后的清理规则。
