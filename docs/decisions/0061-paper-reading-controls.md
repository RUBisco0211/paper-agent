# 0061 文献阅读布局与快捷操作

- DATE: 2026-10-07
- TAGS: frontend, library
- STATUS: 当前
- SUPERSEDES: —

## DECISION

PDF 工具栏与分块 tab 栏等高。右侧分块栏默认宽于旧版，并可拖拽调整；保留收起按钮。文献信息使用 info 图标按钮。PDF 区支持 Ctrl/⌘ 加滚轮或加减键缩放，Shift 加滚轮或左右方向键横向滚动；放大后的页面须可横向到达完整内容。

## REJECTED

- 只增大固定侧栏宽度：不同屏幕与图片、公式内容需要用户自行调整。
- 让浏览器处理 PDF 内的 Ctrl/⌘ 滚轮：会缩放整个网页。

## RATIONALE

阅读文献与查看分块共用主区域，两个栏的对齐和可调整空间直接影响核对效率。

## OUT OF SCOPE

持久化侧栏宽度、PDF 适应页宽模式、触控手势配置。

## OPEN

浏览器中的实际拖拽与快捷操作由用户回测。
