# 0017 Cron 定时检索文献是既定方向，不在 MVP

- DATE: 2026-10-05
- TAGS: product, agent
- STATUS: 当前
- SUPERSEDES: —

## DECISION

Cron 定时检索文献（例如定时检索新入库或新发表的文献并汇总）**是要做的功能，不是不做项**。它不在本次 MVP 范围内，但作为重构后明确的后续方向记录在案 —— 选型时框架是否具备该能力是加分项（agentscope 内建 cron schedule，已确认具备）。

## REJECTED

- 把它写进「明确不做」清单：会让它下次被当成已否决项，丢掉一个已确认的产品方向。
- 现在就进 MVP 范围：需要先定义「定时什么、检索条件从哪来、结果在哪看、如何计费」，MVP 阶段没有余量。

## RATIONALE

产品意图已经明确（用户确认「这个很重要」），只是排期在后。决策记录里区分「不做」与「后置」——前者是否决，后者是待排期，混在一起会让下一次评估失去依据。

## OUT OF SCOPE

具体的定时粒度、检索范围（个人全库 / 项目）、结果呈现形式（新会话 / 通知 / 报告）、费用上限。

## OPEN

结果投递形态（新开会话 vs 生成一份报告 vs 站内通知）；触发来源（用户手动创建 vs 系统默认）。
