# 0073 手动在线检索文献

- DATE: 2026-10-08
- TAGS: product, retrieval, frontend, ingest
- STATUS: 当前
- SUPERSEDES: 无

## DECISION

全局导航增加「在线检索」与 `/discover`。登录用户可通过 `/discover-papers` 手动查询 0072 的聚合学术来源，无需创建会话。结果展示来源、书目信息、DOI 和来源提供的开放 PDF 链接；部分来源失败时继续展示已有结果并提示。用户最多选择 10 篇有 DOI 的候选，在统一业务弹窗中选择全局或项目范围后，逐项调用已有 DOI 入库接口；至少一项成功受理才打开入库队列。手动检索结果不产生 Citation，也不使用会话绑定的候选授权令牌。

## REJECTED

- 为手动检索创建空会话：检索是独立页面动作，不应产生对话记录。
- 让浏览器直接调用外部学术 API：跨源限流、错误语义和结果格式应由业务服务统一处理。
- 为手动选择再建一套批量入库任务模型：现有单篇导入与队列已经覆盖任务生命周期。

## RATIONALE

手动检索与 Agent 检索共享来源与候选语义；用户点击入库即可直接授权现有导入流程。

## OUT OF SCOPE

无 DOI 候选自动入库、新的 PDF 获取方式、搜索历史与外部候选引用。

## OPEN

无。
