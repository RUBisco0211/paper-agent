# 0028 会话与流式：框架不覆盖的那部分

- DATE: 2026-10-05
- TAGS: agent, product
- STATUS: 当前
- SUPERSEDES: `docs/overview/minimal-mvp.md` F06（已删除）

## DECISION

模型与思考强度只能从后端目录选择，且只展示 Model Card 真实支持的档位，目录外参数由后端拒绝。对话输入区可上传 PDF：全局会话加入个人库，项目会话同时加入项目。停止保留已生成内容并标记中断，未完成的工具调用补齐错误 / 中断结果。刷新后读取历史并从事件游标衔接活动生成；用户离开页面不等于停止；后端重启造成的中断必须明确展示。

## REJECTED

- 前端自由填模型参数或思考强度。
- 停止时丢弃已生成内容。
- 离开页面即停止生成。
- 把「重连中」「已中断」显示为正常完成。

## RATIONALE

会话的持久化与中断语义已由 0009 与 0016 交给框架，本条只记框架不管的交互与配置约束。

## OUT OF SCOPE

分支（0009 已否决）、历史编辑、导出。

## OPEN

会话内上传 PDF 时的归属确认与进度展示形态。
