# 0064 对话页项目文献侧栏

- DATE: 2026-10-08
- TAGS: frontend, chat
- STATUS: 当前
- SUPERSEDES: —

## DECISION

项目文献管理入口位于项目行右侧图标操作区，不占用会话列表条目。项目会话顶栏右侧图标控制文献侧栏的展开与收起。会话与文献顶栏等高；文献侧栏可拖拽调整宽度。

## REJECTED

不在项目会话列表中保留单独的“项目文献”条目；不开设与会话顶栏错位的侧栏外置开关。

## RATIONALE

项目操作与会话导航各有固定位置，文献查看时主区域可按窗口宽度调整。

## OUT OF SCOPE

定时任务运行会话和全局会话的文献侧栏。

## OPEN

无。
