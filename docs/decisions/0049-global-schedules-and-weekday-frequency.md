# 0049 定时任务的范围、运行会话与页面

- DATE: 2026-10-07（2026-10-09 合并整理）
- TAGS: product, agent, data, frontend
- STATUS: 当前
- SUPERSEDES: 0017、0046–0048、0050–0052；保留其中仍有效的行为与否决理由

## DECISION

用户保存自定义 prompt、任务时区和执行时间，范围可选全局或自己拥有的项目。全局任务 `project_id=NULL`，运行只检索用户文献库；项目任务只检索所属项目。AgentScope 持有 schedule、cron 触发与各次独立 session/messages；业务库持有 `schedule_id → user_id/project_id` 及每次运行的范围绑定。绑定失败不得开放文献工具。任务 `stateful=false`，新运行不带入旧运行的完整历史或用户追问；用户可在单次运行会话继续对话。项目删除前须处理该项目任务。

Agent 可在用户明确提出后调用 `create_scheduled_task`；定时任务的无人值守运行会话不得再次创建任务。工具只接收名称、用户 prompt、明确的本地时间和可选的一周内执行日；明确的口语时间由工具规范为 `HH:MM`，只有无法确定时刻才追问，未指定执行日默认每天。时区不向模型暴露，从 0078 的用户配置读取，缺失时用实例默认值。用户和项目范围从当前会话绑定取得，模型配置从 AgentScope 当前会话继承；传入 AgentScope 的会话 ID 保留其无连字符格式。项目会话创建的任务默认归属该项目，全局会话创建全局任务。业务内部 HTTP API 校验归属并编排“创建禁用任务 → 绑定范围 → 启用”，失败时清理已创建任务；不得让模型提交用户、项目或任意 cron 参数。默认通过 AgentScope HITL 逐次确认：会话页提示待授权，用户打开预填的现有新建弹窗，可编辑任务内容，点击「确认创建」后以编辑后的参数恢复同一次工具调用；仅关闭弹窗保持待授权，明确拒绝才取消。成功结果向模型返回实际任务的名称、prompt、时间、时区、执行日、cron 和归属，避免模型沿用旧草稿。

账号后端按 0078 的用户配置存储「以后总是允许」设置；开启时该工具跳过逐次内容审查，未开启时含绕过权限模式也需当场确认，无人值守运行仍不能创建任务。设置页入口后置。

每天、每周指定一天、工作日、周末及自定义多选星期几均受支持；自定义至少选一天，cron 用英文星期名，按任务时区触发。全局时钟入口名称为「定时任务」，路由 `/scheduled`，旧 `/calendar` 重定向；默认月视图。侧栏沿用对话页的项目分组、折叠、条目与悬浮操作样式，全局任务单列「全局」组，分组加号预选范围；主区域始终保留新建入口。任务详情在较宽的右侧抽屉，标题栏右侧用带提示的图标按钮承载状态、刷新、删除与关闭。

点击运行记录直接在 `/scheduled/:scheduleId/runs/:sessionId` 主区域打开完整会话，保留任务侧栏并可返回月视图；须校验用户和任务归属。运行会话只出现在任务页，不进入普通对话列表。时间按任务时区显示，AgentScope 无时区后缀的 session 时间按 UTC 解析；消息表格使用单层边框并支持横向滚动。

## REJECTED

- 强制任务归属项目或自动绑定首个项目：与全局检索范围不符；直接展示未绑定的 AgentScope schedule 也无法授权。
- `stateful=true` 复用同一 session、把旧 run 追问加入下次 prompt，或把运行混入普通对话：会意外累积上下文。
- 另建调度 worker 或复制回答正文到业务库：AgentScope 已持有持久任务与消息。
- 数字星期 cron、允许自定义零天：存在星期解释差异或没有明确触发日。
- 只在抽屉预览运行、用额外按钮才打开会话，或按浏览器本地时区解析无后缀 UTC：入口隐蔽且时间错误。
- 为尚未接通的任务伪造示例或入口：会把未实现能力呈现为已可用。
- 关闭审核弹窗即拒绝或按 Agent 原草稿创建：关闭应保留待授权，修改后的内容才是实际执行依据。

## OUT OF SCOPE

跨运行记忆、自动重试、费用上限、通知投递、多实例调度、其他日历视图。

## OPEN

自动重试与费用上限如需实现，另行设计。
