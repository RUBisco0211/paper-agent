# 0066 分块定位交互

- DATE: 2026-10-08
- TAGS: frontend, library
- STATUS: 当前
- SUPERSEDES: 0057 的整块点击跳转行为

## DECISION

点击分块正文不跳转。每个块在复制按钮左侧提供带提示的定位图标按钮；复制按钮同样提供提示。定位后的 PDF 高亮可通过点击文献空白处取消，取消时保留当前阅读位置。

## REJECTED

不以整块卡片作为跳转按钮；不让取消高亮导致阅读位置回到第一页。

## RATIONALE

分离阅读、复制和定位操作，避免误跳转。

## OUT OF SCOPE

PDF 任意区域标注与永久保存高亮。

## OPEN

无。
