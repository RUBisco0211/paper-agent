# 0025 会话范围只有两种：全局与项目

- DATE: 2026-10-05
- TAGS: product, agent
- STATUS: 当前
- SUPERSEDES: `docs/overview/minimal-mvp.md` F04 的三范围设计（已删除）

## DECISION

**只有两种会话范围**：全局（覆盖个人库全部条目，默认）与项目（只覆盖该项目当前文献）。会话绑定项目，一个项目可以有多个会话；范围创建后不可改并在界面持续可见。**单篇文献会话取消** —— 针对一篇提问改为建一个只放那一篇的项目。项目的文献列表**不注入会话提示词**，Agent 通过工具按范围取（0011 / 0027）。项目只能引用本人条目（含待补全文），文献只增不减；补齐 PDF 不改变成员关系。删除项目不删个人库文献，但终止并清理项目会话。

## REJECTED

- 单篇文献会话：为它要单独维护一种范围表达与一套注入机制，收益不抵成本。
- 把文献清单写进 system 提示：上下文随项目增长而膨胀，且模型可见范围可被提示注入绕过。
- 会话创建后允许改范围。
- 项目提供移除文献的接口。

## RATIONALE

范围只有两种来源，机制就只需要一套；文献清单交给工具按需取，上下文不随库增长。

## OUT OF SCOPE

单篇范围、范围变更、项目文献移除、跨项目会话。

## OPEN

删除项目时会话的处理语义：终止、删除还是归档。
