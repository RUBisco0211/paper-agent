# 0032 界面文案：只说用户需要知道的事

- DATE: 2026-10-05
- TAGS: frontend, product
- STATUS: 当前
- SUPERSEDES: `docs/frontend/ui-spec.md` §1（已删除）

## DECISION

界面文案只有三种合法用途：**当前状态**（正在做什么、结果是什么）、**下一步动作**（按钮与空状态引导）、**后果确认**（不可逆操作前需要判断的信息）。禁止出现：实现细节与部署方式、数据流向与隐私机制、内部存储与安全权衡、架构术语与验收口径、面向开发者的说明、页面副标题与品牌口号。按钮用名词 / 动词短语，同一动作全站同词；placeholder 只用于格式示例或选择提示。错误提示必须给出稳定、可行动的信息。不得为规格未提供的能力放入口。

**用语**：文献（不用论文 / 文档）、全局（不用全库）、重命名、提问 / 新建会话、获取元数据、编辑信息、引用原文；状态用「可检索 / 处理中 / 处理失败 / 待补全文」。不在界面暴露「能力」这类内部抽象、内部枚举、内部 ID 与计数。

## REJECTED

- 在界面解释「PDF 会发往 MinerU」「Key 存在浏览器不落库」这类机制说明。
- 页头副标题与品牌口号。
- 为后置能力（移除文献、删除论文）放置入口。
- 把内部 citation id、阶段尝试次数暴露给用户。

## RATIONALE

与组件库无关（0014 换了基座也不影响），是产品层的约束。

## OUT OF SCOPE

品牌视觉、营销文案、帮助中心文档。
