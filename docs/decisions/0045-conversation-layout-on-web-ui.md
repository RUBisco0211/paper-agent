# 0045 对话页采用 web_ui 的双层导航与项目文献侧栏

- DATE: 2026-10-06
- TAGS: frontend, product
- STATUS: 当前
- SUPERSEDES: 0033 中全局侧栏承载项目会话列表的布局约束

## DECISION

全局导航固定为只有图标的窄栏，悬停显示页面名称，左下角头像承载账户操作。每个页面拥有自己的固定侧栏。项目入口和路由改为「对话」与 `/chat`；对话页侧栏按项目分组会话，主区域打开最近一条会话，项目文献显示在可收起的右侧栏。模型与受支持的思考强度放在输入框外侧控制区。日历沿用 web_ui 月视图，仅作未来定时任务的界面容器；模型设置沿用其双栏页面样式。

## REJECTED

- 全局侧栏同时承载导航和会话列表：页面职责混杂，无法给文献库、日历和模型设置各自提供侧栏。
- 保留项目列表作为对话入口：打开后仍需二次点击才能进入会话。
- 在日历放置尚未实现的任务创建按钮：会暗示定时任务已可用。

## RATIONALE

沿用 web_ui 的图标栏与页面侧栏分工，同时把项目范围和文献列表放到对话上下文中。

## OUT OF SCOPE

定时任务执行、会话范围变更、Agent 工具与引用契约。

## OPEN

无。
