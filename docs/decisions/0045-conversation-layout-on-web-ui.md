# 0045 全局导航、对话工作区与会话草稿

- DATE: 2026-10-06（2026-10-09 合并整理）
- TAGS: frontend, product
- STATUS: 当前
- SUPERSEDES: 0064、0067、0071、0076；吸收 0075 的页面侧栏修正

## DECISION

下述固定背景色由 0080 的 SMUI 语义 token 取代；布局、导航与会话行为不变。

全局导航为不可展开的窄图标栏，悬停显示路由名称，左下角头像承载账户操作。对话入口为 `/chat`，侧栏按全局与项目分组展示会话；文献库与在线检索列表、文献阅读页不额外占用无操作价值的左页面栏。已访问的对话、文献库、在线检索、定时任务与设置入口切换时保留组件状态和最后完整路径，退出应用布局即清除缓存。页面路由切换仅为保活容器重播短暂的淡入与轻微上移，遵守减少动态效果设置。

对话工作区顶部是横跨会话侧栏、主区域和项目文献栏的单行工具栏，显示当前会话标题与会话侧栏开关；不使用会话 tab。URL 是当前会话的唯一来源，左侧会话列表负责切换；`/chat` 显示空白工作区。全局图标栏与工具栏在亮色模式使用 `#f7f8f9`，深色模式使用侧栏主题色；对话列表侧栏沿用原背景。项目文献放在可收起、可拖拽调宽的右栏，允许宽于会话主区域；列表中的文献在右栏打开共用阅读器，返回按钮回到列表；项目行右侧提供新会话与文献栏开关，展开菜单提供添加文献、管理文献、重命名及删除，不在会话列表加“项目文献”条目。各页面顶栏统一为 48px；模型与思考强度位于输入框外的控制区。新建会话只导航到统一的 `/chat/new` 草稿页，项目范围（含全局）只在草稿页输入区选择，首条发送才创建 AgentScope 会话与业务绑定；发送失败时保留输入和已创建的会话供重试。既有会话在配置未就绪时仍可输入，仅发送等待必要条件。

已有全局会话同样显示右侧文献栏，读取当前用户的个人文献库；项目会话仍只显示项目文献。右栏共用阅读、引用、调宽与收起展开交互，工具栏提供文献栏开关；空白工作区不显示文献栏；新会话草稿页同样显示文献栏，并与输入框选择的全局或项目范围同步，切换范围重置搜索、分页与阅读状态。新建与已有会话、全局与项目范围统一复用 `ConversationPapersPanel`。草稿页同样可从文献阅读器向输入框添加引用、编辑评论与移除，最多 8 处且允许仅带引用发送；切换范围清空待发送引用，首条消息经已有引用接口提交，失败重试保留原引用，不提前创建持久会话。全局与项目文献栏顶部均提供搜索框：全局通过个人文献库 API 搜索库内文献，项目通过项目文献 API 的 `q` 参数仅搜索当前用户在该项目内的文献，过滤后再计算总数与分页，不调用在线检索；全局与项目列表均每批加载 200 条，滚到底部追加下一批，不显示页码或翻页按钮；搜索词变化从第一批重新加载。

会话侧栏与项目文献栏折叠、展开使用短暂宽度过渡；可调宽栏展开时恢复原有宽度，并遵守减少动态效果设置。文献阅读页的分块侧栏使用相同过渡。

普通与定时运行会话的消息快捷栏贴主区域右边并在可用高度内居中；收起时刻度等长，悬停时原刻度与消息摘要逐行对齐、一起滚动，不新画一组刻度。当前消息高亮，点击按消息 ID 定位；窄屏或不足两条消息时隐藏。快捷栏取代滚动指示按钮。模型设置沿用 web_ui 双栏风格；定时任务的独立布局与运行入口见 0049。

## REJECTED

- 全局图标栏同时承载项目会话列表，或把项目列表作为对话入口：会造成页面职责混杂和二次点击。
- 给文献库、在线检索强留重复标题的页面侧栏，或把项目文献做成会话条目：占用内容区且混淆导航。
- 点击新建立即持久化空会话、配置加载时禁用输入，或首条发送失败重建会话：会产生空记录或丢失输入。
- 左侧且随屏高拉满的稀疏消息刻度、悬停后另画刻度、另造消息滚动状态：与已确认的紧凑右侧导航不符。
- 切换全局入口时卸载页面：会丢失搜索输入与会话位置。

## OUT OF SCOPE

跨刷新保存草稿内容、跨用户复用缓存、持久消息书签。

## OPEN

无。
