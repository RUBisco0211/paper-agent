# 0076 全局导航页面保活与入库队列详情入口

- DATE: 2026-10-09
- TAGS: frontend, product, ingest
- STATUS: 当前
- SUPERSEDES: —

## DECISION

全局图标侧栏的对话、文献库、在线检索、定时任务和模型设置页面在切换时保留已访问页面的组件状态，并记住各入口最后访问的完整路径。返回入口时恢复其原页面和交互状态；退出应用布局后清除缓存。

入库队列中已有文献条目的任务点击后关闭队列，打开该文献的入库详情右侧抽屉，保持当前路由。尚未产生文献条目的任务只显示进度，不提供文献跳转。

## REJECTED

- 切换全局入口时重建页面：会丢失搜索输入、会话位置等未提交的界面状态。
- 从入库队列直接跳转到文献阅读页：处理阶段和失败信息应先在入库详情抽屉中查看。

## OUT OF SCOPE

跨刷新持久保存页面状态、跨登录用户复用缓存、改变入库任务状态或文献阅读页。

## OPEN

无。
