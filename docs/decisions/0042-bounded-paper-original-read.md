# 0042 后续提供有界的文献原文读取工具

- DATE: 2026-10-06（2026-10-23 修订：移除按引用回查工具后重新表述分工）
- TAGS: agent, product, ingest
- STATUS: 当前
- SUPERSEDES: —

## DECISION

文献入读流程完成后，为 Agent 增加直接读取文献原文的只读工具，以 MinerU 解析并保存的 Markdown 为来源，按需返回有限片段，不默认返回整篇。读取必须受当前用户与会话的文献范围约束。现阶段的 Agentic RAG 继续使用 `search_papers`；当前工具边界见 0026，本条所述新原文工具尚未实现。

已登记引用的核对不再由模型承担。`search_papers` 返回的片段即本次证据的全部内容，前端按 `session_bound_citations` 保存的拍平块列表跳转到原文；模型侧不提供回查工具。

## REJECTED

- 以回查工具替代主动阅读：检索已返回同一份片段，回查在信息上重复。
- 一次向模型返回整篇 Markdown：长文会挤占上下文且难以控制成本。
- 允许模型传对象存储路径直接读取：绕过文献归属和会话范围校验。

## RATIONALE

检索片段适合定位相关证据；Agent 对已选中的文献还需要按需阅读更连续的原文。MinerU Markdown 已作为解析产物保存。用户核对引用是界面职责，不需要模型参与。

## OUT OF SCOPE

本次实现工具、改变当前工具白名单、整篇原文注入。

## OPEN

文献入读流程完成后确定选择片段的参数、文本预算、Markdown 缺失时的行为与引用登记关系。
