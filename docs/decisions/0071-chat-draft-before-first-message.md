# 0071 新会话先显示草稿页，首条消息才创建

- DATE: 2026-10-08
- TAGS: frontend, product
- STATUS: 当前
- SUPERSEDES: 0045 中点击新建会话立即创建会话的交互

## DECISION

全局和项目分组的“新建会话”入口只导航到对应范围的草稿页；草稿页不创建或持久化会话。主区域居中显示引导文本、模型与思考强度选择及输入框。用户发送首条消息时，按草稿页范围创建 AgentScope 会话和业务绑定，再触发首条消息并进入会话页。发送失败时保留待发送内容与已创建的会话供重试，避免重复创建。项目草稿页仍显示该项目的文献侧栏。

既有会话的输入框在历史、绑定或模型配置尚未就绪时仍可键入；仅发送动作等待必要条件，就绪前保留已输入内容。

## REJECTED

- 点击加号立即创建空会话：频繁切换会留下大量没有消息的记录。
- 加载配置时禁用整个输入框：用户无法预先输入问题。
- 首条发送失败后每次重试都创建新会话：会产生重复空会话。

## RATIONALE

草稿只存在于页面状态，持久化与用户真正发问绑定；输入与发送分离后，后台数据加载不会阻断写作。

## OUT OF SCOPE

会话数据模型、Agent 工具、历史消息迁移与草稿跨刷新持久化。

## OPEN

无。
