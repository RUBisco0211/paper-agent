# 0036 检索注入与会话范围合并验收

- DATE: 2026-10-05
- TAGS: arch, agent
- STATUS: 当前
- SUPERSEDES: —

## DECISION

将 TODO 中 R3 检索注入与 R4 会话范围合并实施和验收。业务侧先建立 `session_binding`，检索工具再按绑定范围调用业务服务，项目范围和全局范围均需验证。

## REJECTED

- 先独立完成 R3：会依赖尚未建立的范围绑定，无法证明检索隔离。
- 先独立完成 R4：虽可实施，但会延后验证范围对 Agent 工具的实际约束。
- 临时复用旧会话表：使即将替换的会话实现继续成为新检索链路的依赖。

## RATIONALE

检索注入的核心验收条件是会话范围隔离，两者共享同一服务端绑定契约。

## OUT OF SCOPE

更改全局与项目两种范围的产品定义。

## OPEN

业务服务内部检索 API 的认证方式仍按 0027 待定。
