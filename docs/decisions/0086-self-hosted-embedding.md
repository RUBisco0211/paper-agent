# 0086 — 平台自部署统一向量化

- DATE: 2026-10-23
- TAGS: retrieval, ingest, deployment
- STATUS: 已被 0087 局部取代（自部署与 MinerU 部分）

## DECISION

- 解析与向量化产物由所有用户共享，因此由平台承担计算，不使用用户的 embedding Key。
- 开发与部署统一使用 `BAAI/bge-large-en-v1.5`，1024 维；TEI 仅监听本机端口，应用调用 `/v1/embeddings`，不发送密钥。
- 本期假设论文是英文，用户可以中文提问；Agent 在生成 `search_papers` 参数时用英文表达查询，不增加独立翻译调用。
- 一篇论文仍为一个入库 job；流水线将全部待处理 chunks 一次交给适配器，仅适配器按模型档案切分请求，删除流水线固定 32 条的重复分批。
- 不新增按用户的 job 并发限制，保留现有 worker 调度。Embedding 对 429 和暂时性 5xx 进行有界指数退避重试，耗尽后明确失败。
- 检索通道状态仅为 `ok / unavailable`；整体为 `ok / degraded / unavailable`。正常检索零命中不是失败；没有可检索正文时整体与两个通道均为 `unavailable`。所有 detail 使用英文短语。
- `list_papers` 工具描述说明现有 capabilities 中全文、关键词索引与向量可用性，无需新增状态字段。
- MinerU 方向改为无 Key 自部署，具体部署与接口约束见 0087；验收以真实容器测试为准。

## REJECTED

- 用户 Key 支付共享文献的向量化：先入库用户承担共享资产的费用，权责不清。
- 开发和部署各用一个模型：增加维护成本，且同维度并不代表向量兼容。
- 按用户拆 worker 或增加 job 认领限制：本期只需要普通网络服务调用，不为此扩大调度复杂度。
- 每 32 个 chunks 再包装一批：与适配器按请求上限切分重复。
- 独立 LLM 翻译服务：Agent 原本就生成工具参数，无需新增调用。

## OUT OF SCOPE

自动迁移或重算存量向量、多模型共存、中文论文质量支持、额外测试机器。

## OPEN

- 已有其他模型生成的向量不能与 bge-large 混用；切换模型后存量重算另行授权，本次不修改用户数据。
- Tavily 测试连接及上游原始报错弹窗待独立收尾，本次不留下指向不存在接口的按钮。
