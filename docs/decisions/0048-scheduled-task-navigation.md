# 0048 定时任务统一入口与月视图

- DATE: 2026-10-07
- TAGS: frontend, product
- STATUS: 当前
- SUPERSEDES: 0045、0046、0047 中将任务页面称为「日历」的界面命名

## DECISION

全局导航使用时钟图标与「定时任务」名称，页面路由为 `/scheduled`；旧 `/calendar` 跳转到新路由。定时任务的创建、按项目查看、运行记录、暂停、恢复和删除集中在此页，默认使用月视图。主区域始终显示「新建定时任务」按钮，创建时在弹窗中选择所属项目；项目列表加载失败也不能隐藏创建入口。

## REJECTED

- 保留「日历」作为入口名称：用户无法从名称判断这里能管理定时任务。
- 把任务操作分散到项目页与对话页：任务列表和历次运行会失去固定入口。

## RATIONALE

月视图负责展示触发时间，页面名称和导航应反映任务管理这一主要用途。

## OUT OF SCOPE

调度后端、任务数据模型、其他日历视图。

## OPEN

无。
