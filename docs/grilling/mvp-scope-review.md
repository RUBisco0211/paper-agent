| Q3 会话裁剪 | B：保留 steering/follow-up；分支和导出后置 | 保留待投递队列与安全投递边界，首版不做分支/导出 UI |

## 4. 继续有效与未被采纳的扩展

- 联网标题/关键词搜索后置：本轮 Q1 再次确认，不因借鉴 Agentero 自动提前。
- 不做独立搜索页：当前仅需标识符导入入口和库内筛选；可保持旧决定。
- 三种只读 Agent 工具：用户尚未授权 Agent 自动导入论文或修改笔记，人工标识符导入不等于开放写工具。
- 图表区域工具：本轮复杂引用/图表交互已后置，调研建议不是首版交付。
- steering/follow-up：本轮明确保留，不能因为“最小 MVP”自动删除。
- 多用户、项目与全库范围：原有已确认基线继续有效，不重新反问。

## 5. 本轮收敛结果与实现边界

Q1–Q5 已回答；用户两次选择“参考 Agentero”的分支按已核查行为落地：基础来源核对，以及元数据先入库、全文失败可补齐。

- 无 GROBID 的默认识别适配：前5页词级布局 → Zotero recognizer → 标识符精确查询；该识别服务尽力而为，失败保留占位，正文继续。Python 轻量提取库在实施时验证，不把未验证替代写成既定事实。
- 标识符导入首版必须能按 arXiv/DOI 查询和尝试获取 PDF，允许全文不可得。来源实现建议从 arXiv/Crossref 开始，其他补全源不构成首版完整搜索平台。
- 精确区域高亮、独立布局索引、图表问答、复杂 Citation 体系后置；基本引用仍需真实、可核对、受权限约束。
- 用户论文条目需能先无 PDF 存在，这是必须调整旧模型的业务变化；不得继续把所有列表项等同于有哈希的共享 PDF。

本轮没有授权自动导入、写笔记等 Agent 写工具，没有决定取消项目、多用户或全库范围，也没有把标题搜索提前。实现建议与业务决定在功能文档中分开标注。
